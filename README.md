# Homepage1

This is my personal Full-stack MERN application. It is primarily developed as an exam management and student analytics portal (EduGate).

## 🚀 Features
- **Modern UI:** Responsive interface built with React.js.
- **Tech Stack:** MERN (MongoDB, Express, React, Node.js).
- **Test Series:** Seamless integration for conducting and managing test series.
- **Analytics:** Dashboard for tracking student performance.
- **Authentication:** Firebase integration for secure login/OTP.

## 🛠 Tech Stack
- **Frontend:** React.js, Lucide-react (Icons), Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment:** Integrated with Firebase and other production infrastructure.
