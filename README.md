# Homepage1

Idhi naa personal Full-stack MERN application. Idhi main ga exam management and student analytics portal (EduGate) kosam develop chestunnanu.

## 🚀 Features
* **Modern UI:** React.js based responsive interface.
* **Tech Stack:** MERN (MongoDB, Express, React, Node.js).
* **Test Series:** Seamless integration for conducting and managing test series.
* **Analytics:** Dashboard for student performance tracking.
* **Authentication:** Firebase integration for secure login/OTP.

## 🛠 Tech Stack
* **Frontend:** React.js, Lucide-react (Icons), Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Deployment:** Integrated with Firebase and other production infrastructure.
